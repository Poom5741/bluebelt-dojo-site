How it works

เรียนแบบโรงฝึก ไม่ใช่แบบห้องบรรยาย

ระบบออกแบบมาจากวัฒนธรรมสวมกำหนดสาย: ฝึกจนมือจำ ทดสอบจริง และเลื่อนสายด้วยของจริงไม่ใช่ความรู้สึก

1

อ่านและฝึกในเบราว์เซอร์

บทเรียน interactive ฝัง playground ให้เขียนโค้ดและรันได้ในหน้าเดียว ไม่ต้องติดตั้งอะไรในเครื่อง

docs + inline drills · tests ต้องเขียว
2

ลองดวลจริงปลายโมดูล

ท้าทายปลายโมดูล: ส่ง repo GitHub + ลิงก์แอปที่ deploy แล้ว ระบบตรวจด้วย tests จริง + ตรวจ deployment จริง

automated grading · ผ่านเพราะของทำงาน
3

ขึ้นสายด้วยของที่โชว์ได้

สะสม drills + challenges + capstone จนขึ้นสาย ทุกสายพิสูจน์ด้วยแอปที่ใช้งานได้จริง ไม่ใช่ใบประกาศ
